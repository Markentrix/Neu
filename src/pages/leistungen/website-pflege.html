Warum Pflege

Eine Website ist nach dem Livegang nicht fertig.

Websites laufen auf Technik, die sich ständig weiterentwickelt. Wird sie nicht aktuell gehalten, entstehen Sicherheitslücken, Ladezeiten wachsen und irgendwann funktioniert etwas nicht mehr. Das BSI empfiehlt für Webanwendungen ausdrücklich regelmäßige Aktualisierungen und eine saubere Absicherung.

Mit der Pflege übernehmen wir diese Arbeit. Sie brauchen weder einen eigenen Server noch Software. Inhalte wie Öffnungszeiten, Preise oder Texte ändern wir auf Zuruf im Rahmen der kleinen Änderungen. Größere Anpassungen und neue Seiten gibt es nach Angebot.

Leistungsumfang

Was in der Pflege enthalten ist.

Sechs Leistungen, die in jedem Paket mitlaufen.

Hosting in Deutschland

Ihre Website liegt auf einem Server in Deutschland. Sie brauchen keinen eigenen Server.

Updates

Die Technik Ihrer Website wird aktuell gehalten, damit bekannte Lücken geschlossen bleiben.

SSL-Verschlüsselung

Besucher erreichen Ihre Seite verschlüsselt, erkennbar am Schloss im Browser.

Sicherungen

Ihre Website wird gesichert, damit sie im Notfall wiederhergestellt werden kann.

Kleine Inhaltsänderungen

Texte, Zeiten, Preise und Bilder auf bestehenden Seiten ändern wir laufend im Rahmen der Pflege.

Technische Betreuung

Ein fester Ansprechpartner für Fragen und Störungen, kein Ticket-System, kein Call-Center.

Größere Anpassungen, zum Beispiel neue Seiten oder Funktionen, sind nicht Teil der Pflege und werden nach Angebot umgesetzt. So wissen Sie immer vorher, was etwas kostet.

Was Sie vorher wissen sollten.

Antworten zu Umfang, Laufzeit und Daten.

Was zählt als kleine Inhaltsänderung?

Änderungen auf bestehenden Seiten, zum Beispiel Texte, Öffnungszeiten, Preise oder Bilder. Neue Seiten, neue Funktionen und größere Umbauten sind nicht enthalten und werden nach Angebot umgesetzt.

Brauche ich einen eigenen Server oder Software?

Nein. Hosting, Technik und Sicherung gehören zur Pflege, Sie benötigen weder einen eigenen Server noch Software.

Kann ich kündigen?

Die Pflege hat 12 Monate Laufzeit und ist danach monatlich kündbar. Abgerechnet wird per SEPA-Lastschrift zu Monatsbeginn.

Wo liegen meine Daten?

Ihre Website liegt auf einem Server in Deutschland. Schriften werden lokal geladen, Formulare auf unserem eigenen Server verarbeitet. Details stehen in der Datenschutzerklärung.

Was ist mit meiner Domain?

Eine bestehende Domain übernehmen wir. Sie bleibt Ihre Domain.
