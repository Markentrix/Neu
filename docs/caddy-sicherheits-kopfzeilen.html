Caddy: Sicherheits-Kopfzeilen für alle Kundenseiten

Markentrix-Portal · Stand 26.11.2026 · gilt für alle Kundenseiten, die über den gemeinsamen Caddy-Server ausgeliefert werden

Ausgangslage: markentrix.de sendet bereits alle Sicherheits-Kopfzeilen. Die Kundenseiten (Beispiel elbdetail.de) senden keine davon (Prüfbericht: „Sicherheits-Kopfzeilen 0 von 5“). Ursache: Im Caddy-Block der Kundendomains fehlt der header-Abschnitt. Eine Änderung an dieser einen Stelle behebt es für alle Kundenseiten, an den Websites selbst ist nichts zu tun.

1Snippet ganz oben ins Caddyfile

(kunden-header) {
	header {
		Strict-Transport-Security "max-age=31536000"
		X-Content-Type-Options "nosniff"
		X-Frame-Options "SAMEORIGIN"
		Referrer-Policy "strict-origin-when-cross-origin"
		Permissions-Policy "camera=(), microphone=(), geolocation=(), payment=(self \"https://www.paypal.com\"), interest-cohort=()"
		Content-Security-Policy-Report-Only "default-src 'self'; script-src 'self' https://portal.markentrix.de https://www.googletagmanager.com https://www.paypal.com https://*.paypal.com; style-src 'self' 'unsafe-inline'; img-src 'self' data: https://portal.markentrix.de https://*.google.com https://*.google.de https://*.googletagmanager.com https://*.google-analytics.com https://*.g.doubleclick.net https://*.paypal.com https://*.paypalobjects.com; connect-src 'self' https://portal.markentrix.de https://*.google-analytics.com https://*.analytics.google.com https://*.googletagmanager.com https://*.g.doubleclick.net https://www.google.com https://www.google.de https://*.paypal.com; frame-src https://www.google.com https://*.paypal.com; font-src 'self'; form-action 'self' https://portal.markentrix.de; base-uri 'self'; object-src 'none'; frame-ancestors 'self'"
		-Server
	}
}
Wichtig beim Kopieren: Jeder Wert muss in einer Zeile stehen (im PDF sind die langen Zeilen nur umbrochen). Am sichersten die beiliegende Datei caddy-kunden-header.caddy verwenden, sie enthält genau diesen Block ohne Umbrüche.

2In den Block der Kundenseiten einbinden

In jeden Site-Block, der Kundenseiten ausliefert (z. B. der gemeinsame Block mit on_demand-TLS oder je Kundendomain), eine Zeile ergänzen:

	import kunden-header

Den Block von markentrix.de selbst nicht ändern, er hat bereits eigene Kopfzeilen.

3Prüfen, neu laden, kontrollieren

caddy validate --config /etc/caddy/Caddyfile
systemctl reload caddy
curl -sI https://www.KUNDENDOMAIN.de/ | grep -iE "strict-transport|content-security|x-frame|x-content-type|referrer-policy|permissions-policy"

Pfad zum Caddyfile ggf. anpassen. Erwartet: sechs Zeilen im Ergebnis. Danach die Prüfung im Portal erneut starten.

4CSP nach 3–7 Tagen scharf schalten

Erst ohne Fehler testen, dann im Snippet Content-Security-Policy-Report-Only durch Content-Security-Policy ersetzen, erneut caddy validate und systemctl reload caddy.

Testen auf einigen Kundenseiten, Browser-Konsole offen (F12), es dürfen keine CSP-Meldungen erscheinen:

  • Kontakt- und Terminformular absenden, Fotos hochladen
  • Bewertungen, Preise und PayPal-Knopf (falls genutzt)
  • Karte auf der Kontaktseite laden
  • Einwilligung „Alle erlauben“ (Google Analytics / Google Ads laden)

5Was die Kopfzeilen bewirken

KopfzeileWirkung
Strict-Transport-SecurityBrowser nutzt nur noch HTTPS (1 Jahr)
X-Content-Type-Optionskeine Umdeutung von Dateitypen
X-Frame-OptionsSeite nicht in fremde Seiten einbettbar (Clickjacking)
Referrer-Policyfremde Seiten sehen nur die Domain, nicht den Pfad
Permissions-PolicyKamera, Mikrofon, Standort gesperrt; Zahlung nur PayPal
Content-Security-Policynur erlaubte Quellen für Skripte, Bilder, Verbindungen

6Hinweise

  • HSTS: includeSubDomains bewusst weggelassen. Nur ergänzen, wenn alle Subdomains aller Kundendomains HTTPS haben.
  • Zusätzliche Dienste: Nutzt eine Kundenseite weitere externe Dienste (z. B. Metricool, YouTube, Calendly), deren Domain in den passenden CSP-Eintrag aufnehmen. Am einfachsten über ein zweites Snippet für diesen Kunden statt import kunden-header.
  • Eine Hauptadresse: Falls noch nicht vorhanden, je Kunde die Domain ohne „www“ dauerhaft weiterleiten: 
    kundendomain.de {
	redir https://www.kundendomain.de{uri} 301
}
  • Rückweg: Bei Problemen die Zeile import kunden-header entfernen und Caddy neu laden.

Erstellt für das Markentrix-Portal. Die Werte entsprechen dem Bedarf der Portal-Bausteine (portal.markentrix.de), Google Analytics/Ads, PayPal und Google Maps.
