# Kennzeichnung von KI-Inhalten (Entwurf, vom Anwalt prüfen lassen)

Ziel: Endkunden unserer Kunden merken, wenn sie mit einer KI sprechen oder KI-Texte lesen (Transparenzpflichten nach der EU-KI-Verordnung, Art. 50, sowie Wettbewerbs- und Verbraucherrecht). Ob und wie genau das für jeden Einsatz gilt, klärt die Rechtsberatung. Die Texte unten sind Vorschläge, keine Rechtsberatung.

| Einsatz | Vorschlag |
|---|---|
| Website-Chat | Begrüßung: „Hallo, ich bin der digitale Assistent von {Firma}. Ich bin eine KI und kann Fehler machen. Für verbindliche Auskünfte erreichen Sie uns unter {Telefon}." |
| Telefon-Assistent | Gleich zu Beginn: „Guten Tag, Sie sprechen mit dem digitalen Assistenten von {Firma}." |
| E-Mail-Entwürfe der KI | Wenn Mails ohne Prüfung durch einen Menschen rausgehen: Fußzeile „Diese Nachricht wurde mit KI-Unterstützung erstellt." Prüft ein Mensch jede Mail, ist der Hinweis freiwillig. |
| Berichte, Angebote, Rechnungen | Unterschrift immer „Ihr Markentrix-Team". Optional: „mit KI-Unterstützung vorbereitet". Kein KI-Eigenname. |
| Website-Texte und Bilder | KI-erzeugte Bilder, die echt wirken (Personen, Ereignisse), kennzeichnen. Reine Gestaltung ist unkritisch. |

Weitere Punkte für den Anwalt: Hinweis in der Datenschutzerklärung (Chat-Verarbeitung, Anbieter, Drittland-Übermittlung), Aufbewahrung der Chat-Protokolle, menschliche Übernahme auf Wunsch.
