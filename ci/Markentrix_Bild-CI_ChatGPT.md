# Markentrix · Bild-CI für ChatGPT und andere Bildgeneratoren

Stand: Markenhandbuch 2026, Version 3.0. Grundlage sind die Seiten 19 bis 21 des Handbuchs.

## So wird es benutzt

1. **Einmalig:** Die „Kurzfassung für die Einstellungen“ (Abschnitt 5) in die Projektanweisungen von ChatGPT einfügen.
2. **Je Bild:** Eine Vorlage aus Abschnitt 4 nehmen, das Motiv in den eckigen Klammern ersetzen, dann Stilblock (Abschnitt 2) und Ausschlussblock (Abschnitt 3) darunter einfügen.
3. **Danach:** Bild mit der Abnahmeliste (Abschnitt 7) prüfen. Logo, Text, Kupferstrich und Aufwärtslinie nachträglich einsetzen.

## 1 · Drei feste Regeln

- **Das Logo wird nie von der KI erzeugt.** Es wird nachträglich aus der Logo-Datei eingesetzt. Ein Bild mit erfundenem oder verzerrtem Logo wird verworfen.
- **Text kommt nachträglich ins Bild,** in Canva oder im Layout, mit Archivo und Source Sans 3. Die KI liefert das Bild mit Freifläche.
- **Kupferstrich und Aufwärtslinie zeichnet nie die KI.** Sie kommen aus dem Layout und aus der Datei `assets/aufwaertslinie.svg`.

## 2 · Stilblock (immer anhängen)

```
STIL (Markentrix): Helle, hochwertige, realistische Markenfotografie, wie von einem professionellen Fotografen aufgenommen. Natürliches, weiches Tageslicht von der Seite, keine harten Schatten. Helle, aufgeräumte, echte Umgebung mit viel freier Fläche und natürlichen Materialien: kreideweiße Wände, helles Holz, Leinen, Papier, heller Stein. Gesamtbild hell und ruhig, natürliche, leicht warme Farben, zurückhaltende Sättigung, kein Farbfilter.
Farbakzente sparsam und nur als echte Gegenstände oder Bildschirminhalte: ein tiefes Pfauenblau #045268 (zum Beispiel Arbeitsshirt, Schürze, Tür, Ordner) und höchstens ein kleiner Akzent in Kupfer #C67432 (echtes Kupfer, Leder oder warmes Holz). Dunkle Elemente in Blauschwarz #0C2128 statt reinem Schwarz. Keine weiteren kräftigen Farben.
Menschen: echte, natürlich wirkende Personen aus lokalen Betrieben in Norddeutschland, 25 bis 60 Jahre, echte Arbeitskleidung, natürliche Haut mit Poren, ungestellte Haltung, konzentriert bei der Arbeit oder freundlich im Gespräch, kein Dauerlächeln. Hände anatomisch korrekt.
Aufnahme: Augenhöhe, 35 bis 50 mm Brennweite, Blende f/2.8 bis f/4, scharfes Hauptmotiv, leicht unscharfer, ruhiger Hintergrund. Ein klares Hauptmotiv, mindestens ein Drittel des Bildes als ruhige, helle Freifläche für späteren Text.
Bildschirme im Bild zeigen eine schlichte, helle Oberfläche in Weiß mit einem dunkel blaugrünen Knopf, ohne lesbaren Text.
```

## 3 · Ausschlussblock (immer anhängen)

```
NICHT IM BILD: dunkle oder schwarze Hintergründe, Neonlicht, Glühen, Lichtreflexe, Hologramme, Roboter, Androiden, leuchtende Gehirne, Schaltkreis-Muster, Datenströme, futuristische Bedienoberflächen, Krypto-Optik, Farbverläufe, Cyan, Violett, Magenta, Comic-Stil, 3D-Cartoon-Figuren, Illustration, übersättigte Farben, Orange-Türkis-Look, Stockfoto-Händeschütteln, Models im Anzug, glatte Kunsthaut, verzerrte Hände, Logos, Markennamen, das Markentrix-Logo, Wasserzeichen, Schrift oder Fantasietext im Bild.
```

## 4 · Vorlagen

Das Motiv in eckigen Klammern ersetzen. Darunter immer Stilblock und Ausschlussblock einfügen.

### A · Betrieb bei der Arbeit

```
Foto: [Inhaberin eines Hofladens, etwa 45, in pfauenblauer Schürze, legt frisches Gemüse in eine Holzkiste]. Format [4:5 hoch]. Ruhige helle Freifläche [im oberen Drittel].
```

### B · Smartphone oder Laptop in der Hand

```
Foto: [Kfz-Meister hält in der hellen Werkstatt ein Smartphone], auf dem Display eine helle, schlichte Terminübersicht in Weiß mit einem dunkel blaugrünen Knopf, ohne lesbaren Text. Fokus auf Hand und Gerät. Format [1:1]. Freifläche [rechts].
```

### C · Ruhiger Hintergrund für Text

```
Foto: [heller Holztisch von oben, links unten eine Gartenschere, Handschuhe aus Leder und ein kleiner Kupfertopf], der Rest des Bildes ist eine leere, helle Fläche. Format [1:1]. Mindestens zwei Drittel Freifläche.
```

### D · Vorher und nachher

```
Foto: Zwei Smartphones nebeneinander auf einem hellen Holztisch. Links [eine veraltete, überladene Website in Grau- und Brauntönen], rechts [eine moderne, helle Website in Weiß mit dunkel blaugrünem Knopf], beide ohne lesbaren Text. Format [4:5 hoch]. Freifläche oben.
```

### Serien

Für zusammengehörige Bilder zuerst ein Bild freigeben, dann schreiben:

```
Gleicher Stil, gleiches Licht, gleiche Umgebung wie im letzten Bild. Neues Motiv: [...]
```

## 5 · Kurzfassung für die ChatGPT-Einstellungen

```
Alle Bilder im Markentrix-Stil: helle, realistische Markenfotografie, weiches Tageslicht, viel freie Fläche, aufgeräumte Umgebung mit natürlichen Materialien (helles Holz, Leinen, Papier), natürliche, leicht warme Farben. Akzente sparsam als echte Gegenstände in Pfauenblau #045268, höchstens ein kleiner Akzent in Kupfer #C67432, Dunkles in Blauschwarz #0C2128. Echte, natürliche Menschen aus lokalen Betrieben, 35–50 mm, leichte Hintergrundunschärfe, ein Drittel helle Freifläche für Text. Niemals: dunkle Hintergründe, Neon, Glühen, Farbverläufe, Cyan, Violett, Roboter, Hologramme, Comic, 3D-Figuren, Stockfoto-Klischees, Logos, Schrift oder Fantasietext im Bild. Das Markentrix-Logo nie erzeugen.
```

## 7 · Abnahme: sieben Prüfungen

| Nr. | Frage | Bestanden, wenn |
|---|---|---|
| 1 | Hell? | Kein dunkler Hintergrund, mindestens die Hälfte heller als Mittelgrau |
| 2 | Echt? | Hände, Gesichter, Werkzeug, Tiere und Perspektive sind fehlerfrei |
| 3 | Ruhig? | Ein Hauptmotiv, aufgeräumter Hintergrund, Freifläche vorhanden |
| 4 | Farbtreu? | Pfauenblau und höchstens ein Kupferakzent, kein Neon |
| 5 | Sauber? | Kein Logo, kein Fantasietext, keine Fremdmarke |
| 6 | Glaubwürdig? | Die Szene könnte so in der Region vorkommen |
| 7 | Ehrlich? | Das Bild gibt nicht vor, einen echten Kunden zu zeigen |

Fällt eine Prüfung durch, wird das Bild neu erzeugt.

## 8 · Formate

| Zweck | Erzeugen | Zuschneiden auf |
|---|---|---|
| Beitrag, Karussell | Quadrat 1:1 | 1080 × 1080 px |
| Beitrag hoch | Hochformat 2:3 | 1080 × 1350 px (4:5) |
| Story, Reel | Hochformat 2:3 | 1080 × 1920 px (9:16) |
| Website, Präsentation | Querformat 3:2 | nach Bedarf |

## 9 · Kennzeichnung

KI-Bilder erhalten auf der Website das kleine Abzeichen „KI-Symbolbild“. Sie zeigen nie einen angeblich echten Kunden.

## 10 · Grafiken mit Text

Social-Media-Grafiken mit Überschrift, Knopf und Logo entstehen nicht im Bildgenerator, sondern im Layout (Canva) nach Seite 23 des Handbuchs. Die KI liefert dafür höchstens das Foto oder den Hintergrund nach Vorlage C.

Werte für das Layout:

| Element | Wert |
|---|---|
| Grund | Kreide `#F7F4EE`, als Abwechslung Leinen `#EAE2D3` |
| Überschrift und Text | Tiefsee `#0C2128` |
| Knopf | Pfauenblau `#045268` mit weißem Text |
| Akzent | Kupfer `#C67432`, höchstens einmal, als Strich unter einem Wort |
| Schriften | Archivo ExtraBold für Überschriften, Source Sans 3 für Text |
