# Italia Camper 24 – Shop-Redesign

Statischer Multi-Page-Shop (40 indexierbare Seiten). Quelle: `src/data.py` (Inhalte) + `src/build.py` (Generator) → Ausgabe in `site/`.

    python3 src/build.py   # baut site/ neu (Sitemap, JSON-LD, llms.txt inklusive)

Platzhalter: Rechtstexte, Straßenadressen, Produktfotos, Preise der „auf Anfrage“-Produkte.
